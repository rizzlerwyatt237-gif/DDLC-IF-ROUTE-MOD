# DDLC IF ROUTE MOD

A Ren'Py-based DDLC fan mod inspired by the alternate-timeline / IF-route idea of **Re:Zero**.

## What this is

This project adds a branching IF-route framework to a normal DDLC installation. The routes are original fan-written scenarios inspired by the *concept* of alternate timelines; they are not reproductions of the Re:Zero novels or anime scripts.

### Included routes

- Pride IF
- Wrath IF
- Sloth IF
- Greed IF
- Gluttony IF
- Lust IF
- Vainglory IF
- School IF

Each route has its own opening, choices, route flag, and ending. Completing a route unlocks the route hub so the player can replay discovered timelines.

## Installation

This repository is a **DDLC mod source project**, not a redistribution of DDLC itself.

1. Obtain DDLC from its official distribution.
2. Back up your DDLC `game` folder.
3. Download this repository.
4. Copy `game/if_route_mod.rpy` into your DDLC `game` folder.
5. Launch DDLC normally.
6. Choose **IF ROUTE MOD** from the title screen/menu when the mod entry is available, or start a new game and use the mod's route entry point as described below.

For a conventional DDLC Mod Template project, place this file into the template's `game` directory and build from that project.

## Development

The main source is:

`game/if_route_mod.rpy`

No DDLC, Re:Zero, character art, music, fonts, or other copyrighted game assets are included in this repository. The mod is designed to use assets from a player's legitimate DDLC installation or separately created/licensed mod assets.

## Route design

The route system deliberately treats the IF stories as separate timelines rather than simply renaming the seven deadly sins. The player makes a defining decision, enters a timeline, and receives a route-specific conclusion.
