# DDLC IF ROUTE MOD

A continuous DDLC fan-made psychological-horror campaign inspired by alternate-timeline IF-route fiction.

## Character visuals and player name

The script now displays the living girls using the classic DDLC sprite image names and the correct one-, two-, three-, or four-person transforms. The protagonist is named **MC** in dialogue.

## Full campaign

This is a branching story, not a short demo that returns to a route menu after each scene. It follows an escalating eight-day crisis. Choices affect trust, character bonds, timeline pressure, and who survives. The run reaches one of two terminal endings:

- **The Last Page:** all four club girls are dead.
- **A Girl's Final Choice:** one of the surviving girls kills MC.

There is no route-hub return or peaceful third ending after the campaign starts. The player can still pause, save/load where Ren'Py allows it, or close the game normally.

## Install from GitHub

This repository contains mod scripts only. It does **not** include or redistribute DDLC's original game files.

1. Use a legitimate copy of classic DDLC compatible with Ren'Py 6.99.
2. Back up the DDLC installation's `game/` folder.
3. Open this repository's `game/` folder.
4. Copy both `if_route_mod.rpy` and `if_route_launcher.rpy` directly into DDLC's `game/` folder. Do not copy the repository folder itself.
5. Start DDLC and press **Start Game**. The launcher redirects the built-in start label to the IF Route Mod.

Expected layout:

```text
DDLC/
  game/
    if_route_mod.rpy
    if_route_launcher.rpy
    ...the existing DDLC files...
```

## If sprites still do not appear

The sprite/background image assets must come from the original DDLC installation. This repo does not contain those copyrighted files. If the game shows text but no character art, confirm you copied the scripts into the original DDLC installation's `game/` directory (not a blank Ren'Py project), and send the complete error screen or `traceback.txt` if there is one.
